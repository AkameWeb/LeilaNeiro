# Лейла (Leila) — Саморазвивающийся ИИ с личностью, эмоциями и памятью

[![Python](https://img.shields.io/badge/Python-3.10+-blue.svg)](https://www.python.org/)
[![License](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)

**Лейла** — это исследовательский прототип искусственного интеллекта, разработанный для имитации человеческого развития, эмоционального интеллекта и непрерывного обучения. Проект начинается с состояния «ребёнка» и эволюционирует, формируя собственное мнение, мировоззрение и привычки на основе взаимодействия с пользователем и виртуальной средой.

>  **Важно:** Это исследовательский прототип (MVP), имитирующий черты AGI. Он не обладает настоящим сознанием, но демонстрирует передовые подходы к моделированию личности, памяти, физиологии и эмоций в программном обеспечении.

##  Особенности

-  **Динамическая личность**: Черты характера (эмпатия, юмор, любопытство, интроверсия) меняются со временем и под влиянием пользователя через модуль обучения.
-  **Эмоциональный интеллект**: Система настроений (радость, грусть, покой, скука, раздражение, депрессия), которая напрямую влияет на стиль общения, длину ответов и внутренние решения.
-  **Физиология и циклы сна**: Параметры энергии, усталости и «голода к информации». При истощении энергии Лейла «засыпает», восстанавливает силы и проводит **консолидацию памяти** (аналог человеческих снов для укрепления нейронных связей).
-  **Естественное общение**: Использование внутренних монологов, невербальных привычек (например, `*вздыхает*`, `*кусает губу*`, `*наклоняет голову*`) и контекстно-зависимых реакций.
-  **Модульная память**: Сохранение тем разговоров, частых слов пользователя, истории настроений и собственных мыслей для создания иллюзии долгосрочных отношений.
-  **Саморазвитие**: Архитектура поддерживает динамическую подгрузку модулей (`importlib`) и заложена с расчётом на будущую возможность генерации нового кода самой ИИ для расширения собственных возможностей.
-  **Мультимодальность**: Архитектура предусматривает интеграцию зрения (OpenCV/YOLO), слуха (Whisper), речи (Silero TTS) и осязания в виртуальной 3D-среде (PyBullet).

##  Оценка сложности (для разработчиков)

Согласно архитектурному плану, минимально жизнеспособный прототип (MVP) с базовой личностью, памятью, циклами сна и мультимодальными заглушками составляет **~5000–6000 строк кода на Python**. 
- Ядро личности и эмоций: ~400 строк
- Управление энергией, усталостью и сном: ~350 строк
- Память и модуль обучения: ~500 строк
- Интеграция LLM и генерация ответов: ~1000+ строк
- Остальное: инфраструктура, модули восприятия, тесты и главный цикл.

**Почему Python, а не C++?** Для саморазвивающейся системы критически важна рефлексия и возможность менять структуру кода на лету без перекомпиляции. Python обеспечивает гибкость, скорость итераций и готовую экосистему ML-библиотек. Критические по скорости модули (например, физика осязания) могут быть переписаны на C++ и подключены через `pybind11` на поздних этапах.

##  Технический стек

| Компонент | Технология | Назначение |
|-----------|------------|------------|
| **Язык** | Python 3.10+ | Гибкость, динамическая типизация, экосистема ML |
| **Ядро ИИ** | Hugging Face `transformers`, `torch` | Локальные LLM (например, Llama-3-8B, Phi-3) для рассуждений |
| **Память** | `chromadb`, `sqlite3` | Векторный поиск эпизодов и хранение структурированных данных |
| **Эмоции и состояния** | `pydantic` | Валидация и управление параметрами личности |
| **Зрение** | `opencv-python`, `ultralytics` | Распознавание объектов и лиц (модуль восприятия) |
| **Слух** | `openai-whisper` | Преобразование речи в текст (STT) |
| **Речь** | `silero-tts` | Синтез естественной речи (TTS) |
| **Осязание/Среда** | `pybullet`, `numpy` | Физическая симуляция и взаимодействие с виртуальными объектами |

##  Структура проекта

```text
leila-ai/
├── core/
│   ├── human_personality.py   # Ядро личности: эмоции, энергия, привычки, состояния
│   ├── character_learner.py   # Модуль обучения: адаптация черт характера на основе диалогов
│   └── memory_manager.py      # Управление эпизодической и семантической памятью (ChromaDB)
├── modules/
│   ├── vision.py              # Модуль зрения (интеграция OpenCV/YOLO)
│   ├── audio.py               # Модуль слуха и речи (Whisper + Silero)
│   └── physics.py             # Модуль осязания в виртуальной среде (PyBullet)
├── data/
│   ├── human_state.json       # Сохранённое состояние личности (настроение, энергия, черты)
│   └── memory.db              # Локальная база данных воспоминаний
├── human_responder.py         # Генератор ответов с учётом контекста, эмоций и привычек
├── main.py                    # Точка входа: главный цикл взаимодействия и тик времени
├── requirements.txt           # Зависимости проекта
└── README.md                  # Этот файл
