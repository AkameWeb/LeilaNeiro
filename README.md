##  Особенности

-  **Динамическая личность**: Черты характера (эмпатия, юмор, любопытство, интроверсия) меняются со временем и под влиянием пользователя через модуль машинного обучения.
-  **Эмоциональный интеллект**: Система настроений (радость, грусть, покой, скука, раздражение, депрессия), которая напрямую влияет на стиль общения, длину ответов и внутренние решения.
-  **Физиология и циклы сна**: Параметры энергии, усталости и «голода к информации». При истощении энергии Лейла «засыпает», восстанавливает силы и проводит **консолидацию памяти** (аналог человеческих снов для укрепления связей в данных).
-  **Естественное общение**: Использование внутренних монологов, невербальных привычек (например, `*вздыхает*`, `*кусает губу*`, `*наклоняет голову*`) и контекстно-зависимых реакций.
-  **Модульная память**: Сохранение тем разговоров, частых слов пользователя, истории настроений и собственных мыслей для создания иллюзии долгосрочных отношений.
-  **Саморазвитие**: Архитектура поддерживает динамическую подгрузку модулей (`importlib`) и заложена с расчётом на будущую возможность генерации нового кода самой ИИ для расширения собственных возможностей.
-  **Мультимодальность**: Архитектура предусматривает интеграцию зрения (OpenCV/YOLO), слуха (Whisper), речи (Silero TTS) и осязания в виртуальной 3D-среде (PyBullet).

##  Архитектура и выбор языка

Согласно архитектурному плану, минимально жизнеспособный прототип (MVP) с базовой личностью, памятью, циклами сна и мультимодальными заглушками составляет **~5000–6000 строк кода на Python**.

**Почему Python, а не C++?**  
Для саморазвивающейся системы критически важна рефлексия и возможность менять структуру кода на лету без перекомпиляции. Python обеспечивает гибкость, скорость итераций и готовую экосистему ML-библиотек. Критические по скорости модули (например, физика осязания или обработка видеопотока) могут быть переписаны на C++ и подключены через `pybind11` на поздних этапах развития проекта.

##  Установка и запуск

### 1. Клонирование репозитория

{tb}bash
git clone https://github.com/your-username/leila-ai.git
cd leila-ai
{tb}

### 2. Создание виртуального окружения

{tb}bash
python -m venv venv
source venv/bin/activate  # Для Windows: venv\\Scripts\\activate
{tb}

### 3. Установка зависимостей

{tb}bash
pip install -r requirements.txt
{tb}

>  **Примечание:** для работы Whisper и PyBullet могут потребоваться системные зависимости, такие как `ffmpeg` и `cmake`.

### 4. Запуск проекта

{tb}bash
python main.py
{tb}

После запуска Лейла инициализирует своё состояние, загрузит сохранённые данные (если они есть) или начнёт общение с базовыми настройками «ребёнка».

##  Ограничения и этика

- **Имитация, а не сознание**: Лейла использует вероятностные модели, эвристики и векторный поиск для имитации эмоций. Она не обладает настоящим субъективным опытом.
- **Ресурсоёмкость**: Запуск локальных LLM и векторных баз данных требует значительных вычислительных мощностей (рекомендуется GPU с 8+ ГБ VRAM).
- **Этические аспекты**: Проект предназначен исключительно для исследовательских и образовательных целей. Не рекомендуется формировать глубокую эмоциональную привязанность к программному обеспечению.
